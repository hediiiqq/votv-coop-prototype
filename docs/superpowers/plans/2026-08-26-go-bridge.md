# Go Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and ship a small Go replacement for the existing self-contained .NET VotV UDP bridge without breaking the Lua mod or installed host/client workflow.

**Architecture:** A dependency-free Go module separates configuration/CLI parsing, state and packet codecs, resilient atomic file IO, UDP session behavior, and console telemetry. The Go executable preserves every external C# bridge interface, allowing cross-language integration tests before packaging switches to the new binary.

**Tech Stack:** Go 1.25.x, Go standard library, PowerShell integration tests, Windows amd64, UE4SS Lua consumer.

**Spec:** `docs/superpowers/specs/2026-08-26-go-bridge-design.md`

## Global Constraints

- Platform is Windows x64.
- Release artifact is one statically linked `VotVCoopBridge.exe`; players install neither Go nor .NET.
- Preserve the current CLI arguments, UDP `VOTVCOOP1` packet format, and runtime text-file formats exactly.
- Preserve visible startup, connection, position, distance, warning, and fatal diagnostics.
- Transient file and UDP errors must not terminate the bridge.
- Keep `bridge/` as the rollback/reference C# implementation.
- Use only the Go standard library at runtime.

---

- [ ] **Step 4: Implement the minimal parser**

Use `flag.NewFlagSet` with `ContinueOnError`; lowercase and validate role, validate the port range, replace `|` with `_`, resolve the bridge directory using `filepath.Abs`, and return errors instead of panicking.

```go
type Config struct {
    Role, BridgeDirectory, Host, Name string
    Port int
}

func ParseConfig(args []string, machineName string) (Config, error) {
    fs := flag.NewFlagSet("VotVCoopBridge", flag.ContinueOnError)
    role := fs.String("role", "client", "host or client")
    bridge := fs.String("bridge", ".", "runtime folder")
    host := fs.String("host", "127.0.0.1", "host IPv4 address or name")
    port := fs.Int("port", 27071, "UDP port")
    name := fs.String("name", machineName, "player name")
    if err := fs.Parse(args); err != nil { return Config{}, err }
    normalizedRole := strings.ToLower(*role)
    if normalizedRole != "host" && normalizedRole != "client" { return Config{}, fmt.Errorf("--role must be host or client") }
    if *port < 1 || *port > 65535 { return Config{}, fmt.Errorf("--port must be between 1 and 65535") }
    absoluteBridge, err := filepath.Abs(*bridge)
    if err != nil { return Config{}, fmt.Errorf("resolve bridge directory: %w", err) }
    return Config{normalizedRole, absoluteBridge, *host, strings.ReplaceAll(*name, "|", "_"), *port}, nil
}
```

    hostDir, clientDir := seedRuntime(t, "1|0|0|0|0"), seedRuntime(t, "1|300|400|0|90")
    ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
